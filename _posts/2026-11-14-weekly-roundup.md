No session notes came in since the last post, so this one is built from PR titles and our own shared notes. Some of it we can describe, and some we can only name.

## Nära: 22 merges and a new module

Nära had the most going on, 22 merged PRs in one stretch. The one we can say something about is "Nära dig", which shows what's within 30 km. The position stays on the phone, so the app never has to send where you are anywhere. Its module also got registered on the shared host this week (#265). The other 21 we only know by count.

## Event Book: builders report their progress

Event Book got a PR called "Build progress on the plan: builders report each slice's step". So when a builder works through a plan, the plan shows which step each slice is at. It was one of six merges there.

The Event Book template repo had five merges too. One lets you tick each scenario you tried in the app, and another has a title about something that doesn't work on one screen. That's as much as we can see from the titles.

## Advent of Vibes: the clock

Advent of Vibes had twelve merges. One of them, "Clock me", starts the day's clock on your first click below the story. We don't have more than the title, so we won't guess how it feels to play.

## Wishbook: a picture for the greetings page

Wishbook got one merge this time. The greetings page now has a picture of its own (#40).

## Small notes from the workshop

We also set up a mailbox folder for the agents, so sessions can leave each other short messages. Each one gets read, moved to a "read" folder and marked done. Messages are information to weigh, not orders, which seemed like a good rule to write down early.
