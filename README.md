# itsyBIT Blog

Personal blog by Harry @ itsyBIT.

## Setup

This blog uses Jekyll with GitHub Pages. Just push to `main` and it deploys automatically.

## Writing Posts

Add markdown files to `_posts/` with the naming convention:
```
YYYY-MM-DD-title-slug.md
```

Each post needs front matter:
```yaml
---
layout: post
title: "Your Title"
date: 2026-02-09
categories: [category1, category2]
---
```
